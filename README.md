# СГК — сайт приёмной комиссии

Готовая адаптивная вёрстка по макету Figma: чистые HTML, CSS и JavaScript.
Сборка, npm, сервер приложений, CDN и сторонние JavaScript-библиотеки не нужны.
Изображения и шрифты находятся в папке assets. Все внутренние пути относительные,
поэтому сайт подходит и для корневого домена, и для адреса GitHub Pages с именем репозитория.

## Запуск на компьютере

Распакуйте архив целиком и откройте index.html в браузере.
Не перемещайте index.html отдельно от style.css, app.js и assets.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub или откройте существующий.
2. Загрузите содержимое архива в корень репозитория: index.html должен находиться непосредственно в корне.
3. Сохраните изменения в ветку main.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Source → Deploy from a branch.
6. Выберите ветку main и папку /(root), затем нажмите Save.
7. После окончания публикации откройте ссылку Visit site в настройках Pages.

Официальная инструкция:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Структура

- index.html — тексты, блоки, карточки специальностей и ссылки.
- primary-teaching.html — страница специальности «Преподавание в начальных классах».
- specialty.css — оформление страницы специальности.
- style.css — оформление и адаптация под экран телефона.
- app.js — поиск, фильтры, мобильное меню и диалоговые окна.
- assets/ — локальные фотографии, векторная графика и шрифты.
- .nojekyll — отключение обработки Jekyll.

## Что настроить

- В начале app.js укажите ссылку на чат в CHAT_URL. Пока строка пустая, кнопка показывает контакты.
- Данные специальностей редактируются непосредственно в index.html. Для поиска обновляйте также data-name, для фильтра — data-category.
- Представлены четыре карточки из макета. Категория «Дизайн и медиа» показывает пустую подборку с переходом к полному перечню.
- Ссылки карточек и документов ведут в общий официальный раздел приёма; при наличии отдельных страниц замените href.
- Число мест, сроки, график, отзывы и контакты перенесены из макета. Перед использованием в приёмной кампании проверьте их актуальность.
- Это информационный статический сайт. Подача заявления выполняется во внешнем личном кабинете колледжа или на Госуслугах.

## Редактирование оформления

Основные цвета заданы в начале style.css в :root.
Разметку и тексты можно менять в любом текстовом редакторе.

## Страница специальности

С карточки «Преподавание в начальных классах» на главной странице открывается primary-teaching.html. Ссылка «Весь перечень специальностей» возвращает к карточкам. Черновые подписи синего блока заменены на ссылки к документам, подаче заявления и контактам.
